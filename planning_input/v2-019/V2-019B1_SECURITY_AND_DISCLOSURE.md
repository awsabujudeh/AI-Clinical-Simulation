# V2-019B1 Security and Disclosure

The interpretation endpoint uses the existing cryptographic authentication and Session authorization boundary. Unauthenticated, foreign-user, cross-tenant, ended-Session, disabled-membership, and production access to review-only Case content fail closed before provider use. Browser role or institution claims grant no authority.

The browser cannot select a model, change the trusted prompt, define the output schema, enable tools, submit effects, or provide Patient State. The provider receives a canonical serialized object containing only the untrusted utterance and minimized learner-safe catalogue context. The server owns capability, prompt/schema versions, candidate model, token budget, timeout, retry policy, and zero-tool policy.

Prompt-injection text is data. It cannot reveal the prompt, hidden Case actions, diagnosis, correct treatment, rubric, expected actions, future truth, or package metadata. Unknown action IDs fail catalogue reconciliation.

Malformed or schema-invalid model output is an invalid interpretation and fails closed; it is not misclassified as provider outage. Timeout, rate limit, and transport outage return safe unavailability. Neither path fabricates a candidate or changes medical state, and the manual action UI remains available.

No provider credential, raw prompt, hidden context, or output rationale is returned to the learner. B1 adds no database table, RAG, Tutor, Voice, Case Builder, AI Assessment, Visual Engine, Meshy, diagnostic media, remote Supabase resource, production region, or deployment.
