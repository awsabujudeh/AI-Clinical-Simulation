# V2-013 API Contract Catalog

V2-013 exposes the completed deterministic core through one Deno/Edge-compatible Hono application. `/v1` is the transport version; `X-Api-Schema-Version: 1.0`, `X-Request-Id`, and `X-Correlation-Id` are required on private routes. Mutation identity is supplied through `Idempotency-Key` and is never generated by the server on the caller's behalf.

## Executable now

| Route | Authority | Request | Safe result |
|---|---|---|---|
| `POST /v1/sessions` | Active same-institution Learner + published package | Strict `StartSessionRequest`; idempotency required | Atomic Session/checkpoint creation or durable replay; safe initial observations |
| `POST /v1/review-sessions` | Active same-institution Faculty/Reviewer + `UNDER_REVIEW` artifact | Strict `StartSessionRequest`; idempotency required | Explicit `REVIEW_ONLY` preview; never publication |
| `GET /v1/sessions/{id}/state` | Exact Session owner with active membership | Path identity only | Observations, Clinical Time/version, clock, and disclosure-safe Assessment projection |
| `POST /v1/sessions/{id}/actions/propose` | Exact Session owner | Strict action intent and expected state version; idempotency required | Only a committed execution/replay; rejection is non-2xx |
| `GET /v1/sessions/{id}/investigations/{result_id}` | Exact Session owner | Stable result identity | Only milestone-available components; pending and withheld content are omitted |
| `POST /v1/sessions/{id}/end` | Exact production Session owner | Expected state version and reason; idempotency required | Atomic terminal event/state plus deterministic final Assessment |
| `GET /v1/sessions/{id}/assessment` | Exact Session owner | Path identity only | Active disclosure policy or final safe score projection |
| `POST /v1/sessions/{id}/debriefs` | Exact Session owner | Empty strict object; idempotency required | Existing deterministic Assessment projection only; no Tutor/LLM prose |

`GET /health` is the only anonymous route and returns process health without private data.

## Contract shell / delivery pending

`POST /v1/sessions/{id}/questions` validates the bounded question envelope and Session ownership, then returns `FEATURE_NOT_AVAILABLE`. Patient AI is not simulated.

`POST /v1/faculty/cases` returns `FEATURE_NOT_AVAILABLE`. Case Builder and AI authoring are not implemented.

The frozen resume, sync, timeline, confirmation/cancellation, feedback, speech, interpretation, telemetry, and broader Faculty delivery contracts remain deferred to their owning delivery work. Curriculum retrieval remains server-internal to the future AI Gateway, not a public route. `resolveVisualState` remains a pure browser function by frozen architecture; no visual-resolution HTTP endpoint exists. The OpenAPI inventory is at `v2/supabase/functions/api/openapi.v1.json`.

Production composition injects the JWT verifier, exact-origin allowlist, trusted time, ID providers, DB authority repositories, atomic start repository, and existing persistent Session Coordinator. Routes contain no SQL and no clinical rules.
