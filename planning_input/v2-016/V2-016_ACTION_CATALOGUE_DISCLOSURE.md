# V2-016 Action Catalogue Disclosure

## Source

The learner catalogue is derived server-side from the authorized compiled or review-execution artifact and restricted to the same pinned action identities held by the Session context. The browser receives it only inside `SafeSessionProjection`; it never reads raw Case Package content.

## Exposed fields

- catalogue schema version `1.0`
- stable Action ID and Action type
- authored `ar-JO` / `en-US` labels derived from safe aliases
- permitted parameter definitions, including required status, type, configured bounds, and allowed codes
- confirmation and repeat policy

Aliases are display/interpretation aids only. The submitted stable Action ID is revalidated against the pinned authoritative catalogue before execution.

## Excluded fields

The projection excludes rules, triggers, effects, transitions, hidden prerequisites, clinical facts, source evidence, future scheduler work, rubric/weights, expected or correct actions, critical-action markers, package/module hashes, and review/approval metadata.

Labels use exact authored locale, then authored `en-US`, then the stable Action ID as a governed non-translated fallback. No clinical translation is generated by the UI.

## Security

Session authorization, institution membership, execution authority, Case pinning, CAS, idempotency, and database policy remain server-controlled. Local metadata cannot authorize an unknown action or cross-tenant Session. The STEMI artifact remains `UNDER_REVIEW` and `REVIEW_ONLY`; ordinary learner production start remains denied.
